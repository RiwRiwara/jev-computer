    2 / 5 · gate
    
คำตอบ 4 ข้อ = NAND gate หนึ่งตัว

    
Jev ตอบความน่าจะเป็นว่า “ใช่” — นั่นคือ AND. กลับค่าด้วย inverter (สายเส้นเดียวในฮาร์ดแวร์จริง) ได้ NAND ซึ่งเป็น universal gate: วงจรดิจิทัลทุกชนิดสร้างจาก NAND อย่างเดียวได้

    4 / 5 · เครื่อง
    
ต่อ gate แบบนั้น 2,102 ตัว ได้คอมพิวเตอร์

    
CPU 8-bit, RAM 16 bytes, 10 คำสั่ง. ตัวถอดรหัสคำสั่ง ALU flag program counter และการอ่าน/เขียน RAM ทั้งหมดเป็น NAND. ทุกรอบ clock เบราว์เซอร์ของคุณประมวลผล gate ทั้งหมดตามลำดับ โดยทุก gate ใช้คำตอบของ Jev จาก request ข้างบน

ใครทำอะไร

    
Jev เป็น model ที่ไม่มี memory ข้าม request และเรียกตัวเองไม่ได้ ต้องมีโค้ดเล็กๆ ถือ bit และเดิน clock ให้ — เหมือนแผงวงจรที่ transistor ต้องมีสายไฟ

  

  

    

      
Jev — logic ทั้งหมด

      
    
        
  • ตัดสินว่า gate ให้ค่าอะไร (ตาราง NAND ทั้ง 4 กรณี)
    • 
        
  • ทุกการบวก ลบ carry ถอดรหัสคำสั่ง กระโดด อ่าน/เขียน RAM ได้มาจากคำตอบนั้นผ่าน gate 2,102 ตัว
    • 
        
  • ถ้า Jev ตอบผิด เครื่องจะคำนวณผิด — ไม่มีคำตอบสำรองจาก Python
    • 
      

    

    

      
โค้ด — ไม่มี logic

      
    
        
  • ถือ bit ของ register และ RAM (flip-flop)
    • 
        
  • เดิน clock และส่งค่าไปตามสาย ตาม netlist ใน cpu.json
    • 
        
  • แปลง bit เป็นเลขฐานสิบเพื่อแสดงผล
